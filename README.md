# Final_Year_Project
<h1>RC Robot for indoor fall detection</h1>

<p>
  The Fall Detection car is an Rc tank using a esp32 board connecting to motors that will control the tank using code that will also be using proximity sensors that will keep it from bumping into walls it will also be using a raspberry pi with a raspberry pi camera using the yolo algorithm. it will then take a picture and send it to a database which then will be displayed on a webpage An indoor localisation and mapping method will be investigated to allow the system to estimate the robot's position and associate detected fall events with a location on a map.
</p>
